## 🎨 Visual Design Elements

### Colors in Action
```
Primary Actions (Get Started, Sign In, Create Account)
├─ Background: #8B5CF6 (Purple)
├─ Text: White (#ffffff)
└─ Pressed: #7c3aed (Darker purple)

Secondary Actions (Outline buttons)
├─ Background: Transparent
├─ Border: #8B5CF6 (Purple)
├─ Text: #8B5CF6 (Purple)
└─ Pressed: Darker outline

Accent Elements
├─ Badges: #FBBF24 (Amber)
├─ Focus States: #FBBF24
└─ Success Messages: Green

Text & Backgrounds
├─ Primary Text: White (#ffffff)
├─ Secondary Text: Gray (#9ca3af)
├─ Background: #0f0f0f (Nearly black)
├─ Cards: #1a1a1a (Dark gray)
└─ Borders: #2d2d2d (Lighter gray)
```

### Typography Hierarchy
```
Large Titles (32px)
├─ Font: GeistSans Bold
├─ Used in: Hook screen headline
└─ Example: "Buy & Sell Crypto in Naira"

Section Headers (24px)
├─ Font: GeistSans Bold
├─ Used in: Screen titles
└─ Example: "Welcome, John!"

Body Text (16px)
├─ Font: GeistSans Regular
├─ Used in: Descriptions, instructions
└─ Example: Form labels

Small Text (14px)
├─ Font: GeistSans Regular
├─ Used in: Metadata, timestamps
└─ Example: "By continuing, you agree..."
```

### Spacing System
```
Padding & Margins follow 4px grid:
- xs: 4px (p-1)
- sm: 8px (p-2)
- md: 16px (p-4)
- lg: 24px (p-6)
- xl: 32px (p-8)

Gaps between elements:
- Tight: 8px (gap-2)
- Normal: 16px (gap-4)
- Loose: 24px (gap-6)
```

## ✨ Animation Details

### Entrance Animations
```
Hook Screen:
- Logo: Fade in (600ms) + Float (continuous)
- Title: Slide up from bottom (delayed 200ms)
- Features: Slide up (staggered 200ms each)
- Buttons: Slide up (600ms delay)

Carousel:
- Slides: Fade in on transition
- Dots: Fade in (300ms delay)
- Next button: Slide up (500ms delay)

Auth Screen:
- Logo: Fade in (600ms)
- Tab switcher: Slide up (100ms delay)
- Forms: Slide up (200ms delay)
- Button: Slide up (400ms delay)

Dashboard:
- Title: Fade in (600ms)
- Status card: Slide up (200ms)
- Feature list: Slide up (staggered)
- Button: Slide up (600ms delay)
```

### Interaction Animations
```
Button Press:
- Visual feedback: 80ms opacity change
- Haptic: Subtle vibration
- Color: Darker shade
- Duration: 150ms total

Input Focus:
- Border color change: 200ms
- Background shift: 200ms
- Cursor visible: Instant

Scroll:
- Momentum: Native feel
- Bounce: iOS style
- Parallax: Subtle depth

Swipe (Carousel):
- Response: Instant follow
- Release: Smooth snap
- Deceleration: Natural physics
```

1. Open app → See hook screen
2. Click "Get Started"

5. Land on dashboard
6. See personalized greeting
